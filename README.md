# 成都地铁 1 号线 · SVG 线路图 + 3 车厢列车运行模拟

纯 vanilla 单页网页应用：内联 SVG 绘制成都地铁 1 号线（含支线）全部 35 座车站的**俯视示意地图**，
并让一列 **3 节车厢**的地铁沿线路按站运行：区间加速—巡航—制动进站—到站停车—**开关门**—发车—
终点**折返**，支持点击任意车站让列车导航到该站、iPad 双指缩放/单指平移/双击缩放。

* **零外部依赖、零构建步骤**：没有 CDN、没有 web font、没有图标字体、没有 npm 包、没有模块打包。
  只有 5 个文件 + 内联/内嵌 SVG，直接 `file://` 打开或任意静态服务器托管都能跑。
* 目标设备：**iPad（触摸优先）**，同时兼容鼠标（滚轮缩放 + 拖动平移）。

### 在 iPad 上打开（本机是 WSL2）

`serve.sh` 会自动打印候选地址，步骤：

1. 在 WSL 里运行 `./serve.sh 8080`（已 `--bind 0.0.0.0`）。
2. 在 **Windows 管理员 PowerShell** 里把端口转发到 WSL（只需做一次；`<WSL_IP>` 用 `hostname -I` 查看，
   一般形如 `172.2x.x.x`）：

   ```powershell
   netsh interface portproxy add v4tov4 listenport=8080 listenaddress=0.0.0.0 `
     connectport=8080 connectaddress=<WSL_IP>
   netsh advfirewall firewall add rule name="potato-8080" dir=in action=allow protocol=TCP localport=8080
   ```

3. iPad 与电脑连同一 Wi-Fi，Safari 打开 `http://<Windows 局域网 IP>:8080/index.html`
   （Windows 上用 `ipconfig` 找 IPv4 地址，通常 `192.168.x.x`）。

注意事项：
* WSL2 的 IP 每次重启可能变化，变化后要 `netsh interface portproxy delete v4tov4 listenport=8080 listenaddress=0.0.0.0` 再重加。
* 若 portproxy 不通：可直接访问 `http://<WSL_IP>:8080/`（需 Windows 防火墙放行），
  或把目录复制到 Windows 侧（如 `C:\potato`）用 `python -m http.server 8080` 起服务，
  或直接把 `index.html` 拷到 iPad 用文件 App 打开（file:// 亦可）。
* 页面已禁用双击缩放/橡皮筋滚动/长按选择，并做了 safe-area 留白，横竖屏切换会重算画布尺寸。

## 2. 线路图（俯视示意地图）

* **线路走向**：按真实"南北倒 Y 形"走向绘制——韦家碾在北，经升仙湖/火车北站向南贯穿市区，
  沿人民北路—人民中路—人民南路—天府大道南下，在**四河站**分叉：主线继续南行至科学城，支线东折至五根松。
  曲线用 Catmull-Rom 平滑（过全部车站），端点站外各留一段 `86` 单位的**折返线**延长段（列车在端点可整列停在轨道上）。
* **车站样式**：普通站小圆点、**端点站实心方块圆**、**换乘站双圆环**、支线车站蓝色描边、四河站画分叉点标记；
  每个站下方有一小段浅灰"站台"垫，在轨道下层只从两侧露出。
* **站名标签**：中文站名 + 英文站名 + 换乘线路编号小方牌；沿线左右交替摆放，并有**防重叠排布**：
  候选位依次为 首选侧 → 反向侧 → 上/下偏移 → 旋转 −46°/46°，按"与已放置标签的重叠面积 + 压住其它车站圆点的罚分"取最优解。
  标签字号与偏移**屏幕恒定**（随着缩放反比缩放，`labelScale = clamp(1/k, 0.34, 2.2)`），
  并在低缩放比时做 LOD：仅显示换乘站/端点站/分叉站站名，放大后显示全部。
* **地图底图装饰**：街区纹理 pattern、网格、东西/南北向主干道（白底 + 描边 + 黄色中线）、
  锦江（府南河）与沙河两条水系、升仙湖/麓湖/兴隆湖/天府公园水景、若干公园绿地，
  以及河流湖泊注记。全部为**示意装饰**（见第 5 节：非实测地理）。
* **运行状态**：左上角 HUD 常驻显示 当前站 / 下一站 / 目标站 / 已运行里程 / 速度 / 预计到达 +
  方向（往科学城 或 往韦家碾 或 往五根松）、车门状态（开门中/车门开启/关门中/车门关闭）、运行阶段
  （巡航/加速中/制动进站/停站/折返中/已暂停）。右下角比例尺会随缩放实时换算 km，左上还有指北针。

## 3. 列车（3 车厢）

* 3 节车厢刚性连结：车厢长 `14`、间隙 `1.8`、半宽 `5.0`（地图单位，为可视性做了夸张；真实 6 节 B 型编组见第 7 节）。
* 车体由**路径弧长参数化**生成：以列车前端里程出发，按 `fS = sHead − dir·i·(车长+间隙)`、`rS = fS − dir·车长`
  计算每节车厢首尾，再沿线路采样点用**法向偏移曲线**（`bandPath`）生成车身轮廓——
  因此转弯时整列列车像蛇一样贴着线路弯曲，车头朝向即该点路径切线方向，不会出现穿出线路/脱轨的直杆。
* 车头端做了收窄（鼻锥）+ 深色风挡与车灯，车身带蓝色顶色带、两侧各 4 扇车窗、两侧各 2 组车门。

## 4. 运行模拟

**动力学**（真实时间戳驱动：`requestAnimationFrame` + `performance.now()` 求 delta；单帧 delta 上限 0.12 s，
大 delta 再拆成 ≤ 0.04 s 子步，切到后台再回来不会跳变）：

| 项 | 取值 | 说明 |
|---|---|---|
| 巡航速度 | 60 km/h | 线路设计最高 80 km/h（见第 5 节）；本模拟取 60 作为区间巡航 |
| 加速度 | 0.75 m/s² | 加速到巡航约 185 m |
| 制动减速度 | 0.9 m/s² | 制动距离 v²/2a，进站减速到 0 停在站台中心 |
| 停站 | 4.1 s | 开门 0.9 s → 保持 1.8 s → 关门 0.9 s → 待发 0.5 s（车门叶片沿车身滑动分离，可见开/关动画） |
| 终点折返 | 12 s | 端点站开门→关门→折返换向，再反向运行（明确选择"折返继续运行"，不静默停车） |

* **按站运行**：`remain = |目标站里程 − 当前里程|`，当 `remain ≤ v²/(2a)` 时按制动曲线
  `v = √(2a·remain)` 限制车速并收敛到 0，实现"区间加速到巡航、进站前减速到 0、停在站台中心"。
* **倍速**：1x / 2x / 4x 只缩放仿真时间（`dt×倍速`），显示的速度/里程仍是真实物理量。
* **控制**：暂停/继续、复位（回到韦家碾，清空目标与里程，回到适配视图）、倍速、跟随列车、交路选择
  （韦家碾↔科学城 主线 / 韦家碾↔五根松 支线）、清除目标、站点列表点选、站点信息卡。

### 点击站点 → 列车运行到该站（README 约定的自洽规则）

点击地图上的车站（或点站点列表 / 站点信息卡的"运行到该站"）即设为目标站，随后：

1. 立即用**同一套状态机**在后台"预演"一遍到该站的完整行程（含各站停站与折返），算出**预计到达时长**（游戏内时间）
   与**还需经过的站数**，显示在 HUD 与导航卡片里（括号内为按当前倍速换算的实时时长）；倍速变化会重算。
2. **目标在当前方向前方且同一交路** → 正常逐站运行至该站，到站后清除目标（提示"已到达目标站"，随后继续常规运行）。
3. **目标在当前方向后方** → 继续驶向本方向终点站 → 折返换向 → 再驶向目标站（提示"需先折返/换交路"）。
4. **目标在另一条交路上**（主线 ↔ 支线，例如在主线运行时点五根松）→ 先运行到分叉站**四河**，
   在四河站停站期间切换交路，再前往目标站。两条交路共享"韦家碾—四河"的几何与里程，所以切换时列车位置连续、不会跳变。
   若四河已经在身后，则先到终点站折返，再回到四河切换。
5. 无目标时按交路端点折返循环运行。
